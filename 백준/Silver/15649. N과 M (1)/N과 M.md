해당 문제는 1 -> N 까지의 자연수 중에서 M개를 고르는 순열을 구현하는

문제로서 리스트를 사용하고 contains 메소드를 통해서 중복을 제거하는 방법을

통해서 순열을 구현하였지만, 저는 기존에 배운 visited 방문 배열 방법을

적용해서 순열을 구현하려고 노력하였습니다.

DFS 메소드에 int형 D 변수를 인덱스를 지정하기 위한 파라미터로 선언,

selected 배열을 선언하여 D 위치의 숫자를 순서대로 저장하도록 작성하였습니다.

또한 D와 M이 같아지면 재귀호출이 종료되도록 구성하였고, 조건을 만족하지

못한다면 visited[i] 즉, 방문하지 않은 숫자를 찾아서 true로 변경하고,

DFS(D+1)을 호출하여 재귀호출이 이어서 진행되도록 하였습니다.

또한 호출이 끝나면 false로 재지정하여 백트레킹 구조를 완성하였습니다.

또한 nextToken 메소드를 사용하는 과정에서 데이터가 String 자료형으로

들어오는 문제를 해결하기 위해서 Integer 형변환을 통해서 데이터를

성공적으로 인덱스로 사용하였습니다.
